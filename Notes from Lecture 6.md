Issues with VAE:
* Posterior collapse: Powerful decoder can learn to model p(x) directly and ignore Z, this is essentially completely deterministc
* Prior mismastch -  Sampling Z ~N(0, I) at test time can land in regions decoder was never trained on (actions completely out of distribution)
VQ-VAE 
![[Pasted image 20261103115706.png]]
* Replace continious gaussian latent z with discrete codebook of k learned vectors, avoids posterior collapse
* It uses nearest neighbor to find a specific code (no in between unkown regions like the gaussian case in Vanilla VAE)
* But Nearest neighbor is not differentiable - So we just skip propogating the gradients through it (skip the nearest neighbor part)
* ![[Pasted image 20261103120037.png|485]]
* VQ-VAE still have mean-seeking in outputs due to MSE

DDIM
![[Pasted image 20261104183109.png|438]]
* DDIM decouples number of denoising iterations in training & inference
* DDPM is markovian(next step complete depend on previous step only and has all the data in it) DDIM defines a non markovian forward process that results in the exact same marginal distributions as DDPM.
* DDIM discretizes the probability flow ODE

The issue is we don't want just generation from a simple noise, we woiuld like to condition it on something (image, sound, robot action).

BUT,
It's not so simple, the model can easily ignore the conditioning like it ignores the noise distribution  (hence we need the lengevin part).
SO we do classifier free guidance -  adding the guidance term slowly during the training using the guidance scale

Flow matching:
* Learn velocity field v_theta(xt, t) that transport samples from noise to data along continious paths.
* ![[Pasted image 20261105110729.png|304]]

* Rectified flow - retrains flow matching  on noise-data pairs generated by its own flow, untangling trajectory crossings and straightening paths.
* Why is it good? - straighter paths will create a faster convergence and less time steps 
* ![[Pasted image 20261105112642.png|306]]
* Pi0 (2024) was the first model to introduce - default for most VLAs,
* Instead of sampling the flow time uniformly  they sample from a shifted beta distribution to focus on noisier (harder action predictions) parts of flow
*
Key takeway - since we work on multimmodal MSE will fail mostly, so these methods are highly used (due to conditional)
